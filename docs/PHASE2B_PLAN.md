## 1. 追加・変更する型

### 1.1 性格（`src/engine/types/personality.ts`）

```ts
export const PERSONALITIES = ["diligent", "passionate", "calm", "craftsman", "competitive", "moodMaker", "cautious", "inspired"] as const;
//                             努力家      情熱家        冷静沈着  職人気質      負けず嫌い     ムードメーカー  慎重派      ひらめき型
export type Personality = (typeof PERSONALITIES)[number];
```

### 1.2 プレースタイル（`src/engine/types/playStyle.ts`）

既存の「戦術の型」（`TACTIC_STYLES`）と混ざらないよう、型名は `PlayStyle` にする。

```ts
export const PLAY_STYLES = [
  "striker", "postPlayer", "speedster", "linkman", "poacher",          // FW
  "wingDribbler", "insideDribbler",                                    // FW/MF
  "number10", "boxToBox", "anchor", "ballHunter",                      // MF
  "crosser",                                                           // MF/DF
  "stopper", "coverer", "attackingFullback", "buildUpDefender", "launcher", // DF（launcher = 砲台）
  "boxKeeper", "sweeperKeeper", "aerialKeeper",                        // GK
] as const;
export type PlayStyle = (typeof PLAY_STYLES)[number];

/** 動きの範囲（SPEC 7.6）。2D・3D 表示でも使う */
export type MovementRange = "free" | "fixed" | "wideOnly" | "mostlyWide" | "mostlyInside";

/** 左・中央・右への関わりやすさ（0〜1）。試合エンジンの選手選びと、P3・P4 の立ち位置の計算で共通に使う */
export interface LaneAffinity { L: number; C: number; R: number }

export interface PlayStyleDef {
  id: PlayStyle;
  /** 効果を発揮するポジションの区分（"FW/MF" は 2 つ） */
  groups: ("FW" | "MF" | "DF" | "GK")[];
  movement: MovementRange;
  /** 伸びやすい能力（熟練度で経験点が増える）と、新入生のスタイルを決めるときの重み */
  keyStats: Partial<Record<StatKey, number>>;
  /** 習得しやすい特殊能力 */
  skillAffinity: SkillId[];
  /** 試合で「らしいプレー」を起こす補正（3.3） */
  match: PlayStyleMatchMod;
}
```

ポジションの区分：FW＝CF・WG、MF＝DMF・CMF・OMF・WG、DF＝CB・SB、GK＝GK（WG はフォーメーションによって FW の列にも MF の列にも置かれるため両方に入れる）。

## 2. 性格

### 2.1 生成

- 新入生（自校・CPU 校）：ひらめき型 3%、残りの 7 種類は均等（約 13.9% ずつ）。
- 職人気質は、得意な練習を 1 つ持つ（主ポジションに合う練習から重みつきで選ぶ。例：GK は GK 練習、CB は守備練習）。選手の詳細では「○○練習にこだわりがある」と寸評で見せる。

## 3. プレースタイル

### 3.1 新入生と既存選手のスタイル

- 主ポジションの区分に入るスタイルごとに「能力の傾向の点数」＝ `keyStats` の重みつき平均を出し、点数の高いものほど選ばれやすくする（上位 3 つから、点数の差に応じた重みで 1 つ選ぶ）。ポジションに合うものが必ず選ばれ、能力の傾向が似ていても選手ごとに散らばる。
- 例：CF でシュートが高い → ストライカー／ポーチャー、空中戦とフィジカルが高い → ポストプレーヤー、スピードが高い → スピードスター。

### 3.2 熟練度

- 0〜100。上がり方（初期案）：
  - 出場 1 試合ごとに +2.5（公式戦は +3.5）。出場時間で按分。
  - スタイルに合う練習（`keyStats` を伸ばす練習）1 日ごとに +0.3。
  - 上がるほど上がりにくい：増える量 ×(1 − 熟練度/130)。
  - 性格：「伸ばしやすいスタイル」に当たれば ×1.5。努力家はどのスタイルでも ×1.1。
- 目安：主力は 3 年生で 70〜90、控えは 40〜60。
- **変更**：いつでも（試合中を除く）変えられ、熟練度は 0 に戻る。選べるのは、主ポジションか適性 ◎○ のポジションの区分に入るスタイル（Q6）。

### 3.3 試合での効果（「らしいプレー」）

熟練度を p（0〜1）とし、すべて p に比例して強くなる。**今いる枠のポジションがスタイルの区分に入らないとき（例：ストライカーを CB で使う）は、効果も動きの範囲も出さない（「自由」として扱う）。**

| スタイル | 起きやすくなるプレー（選ばれやすさ） | 質の補正（実効値） | 代償 |
|---|---|---|---|
| ストライカー | ボックス内のシューター ×(1+0.5p) | シュート精度 +3p | — |
| ポストプレーヤー | ロングボール・クロスの的 ×(1+0.6p) | 競り合い +3p | スピード勝負の場面で選ばれにくい |
| スピードスター | カウンターの走者 ×(1+0.6p) | 抜け出し（スピード）+3p | 空中戦の的になりにくい |
| リンクマン | 中央攻撃の出し手に FW でも加わる（重み 0.6p） | 視野・パス +2p | ボックス内のシューターになりにくい |
| ポーチャー | ボックス内のシューター ×(1+0.8p) | ボックス内のシュート +4p | 出し手・ロングボールの的・ポストプレーに選ばれない |
| ウイングドリブラー | サイド攻撃の運び役 ×(1+0.6p) | 1 対 1 のドリブル +3p | クロスの質は上がらない |
| インサイドドリブラー | 中央でドリブルを試みる率 ×(1+0.6p)、ワンツー | ドリブル +3p | サイドの運び役になりにくい |
| No.10 | 中央攻撃の出し手 ×(1+0.5p) | 視野（パスの候補）+3p | 守備の質に加わる重み ×0.7 |
| ボックストゥボックス | 攻撃にも守備にも加わる | 体力の消耗 ×(1−0.1p) | 特化した補正はない |
| アンカー | 中央の守備の質に加わる重み ×(1+0.4p) | 守備 +2p | 攻撃にほとんど加わらない |
| ボールハンター | 奪ってカウンターにつなぐ率 ×(1+0.3p) | 奪取 +3p | ファウル ×1.15 |
| クロッサー | サイド攻撃でクロスを選ぶ率 ×(1+0.5p) | クロスの質 +0.06p | カットインしない |
| ストッパー | 1 対 1 のマーカー ×(1+0.4p) | 対人の守備 +3p | 背後を取られやすい（カウンターで −1p） |
| カバーリング | カウンターを止める役 ×(1+0.5p) | スピード・判断 +3p | 対人で選ばれにくい |

| 空中戦の番人 | — | ハイボール +3p | 1 対 1 −1p |

### 3.4 動きの範囲（ゾーン判定への反映）

今のエンジンは、選手の枠（スロット）のレーン（L・C・R）が一致するかどうかで、攻撃者・守備者・サイドの運び役を選んでいる（`attackers`・`defenders`・`sideAttack`・`defQuality`）。これを、**選手ごとのレーンへの関わりやすさ `LaneAffinity` の重み**に置き換える。

| 動きの範囲 | 枠のレーンが L（R は左右反転） | 枠のレーンが C |
|---|---|---|
| 自由 | L 1.0・C 0.5・R 0.15（今の `defQuality` の重みと同じ。今の挙動に近づける） | L 0.5・C 1.0・R 0.5 |
| 定位置 | L 1.0・C 0.12・R 0.03 | L 0.12・C 1.0・R 0.12 |
| 大外のみ | L 1.0・C 0・R 0 | 利き足の側（両利きはチームの空いている側）の大外だけ：1.0／0／0 |
| 主に大外 | L 1.0・C 0.35・R 0.1 | 利き足の側 1.0・C 0.5・反対 0.1 |
| 主に内側 | L 0.5・C 1.0・R 0.2 | L 0.3・C 1.0・R 0.3 |

- 選手を選ぶときは「重み × これまでの選び方の重み」で選ぶ。レーンで絞り込む場面（例：サイド攻撃の運び役）は、重みが 0.3 以上の選手だけを候補にする。
- 関わった回数を `ms.laneTouches` に数え、balance と単体テストで「定位置・大外のみの選手が担当ゾーン以外にほとんど関わらない（関与の 1 割未満）」を確かめる。
- `laneAffinity(slot, movement, foot)` は `src/engine/match/` の純粋な関数にし、P3・P4 の立ち位置の計算でもそのまま使う。

### 3.5 成長への効果

- スタイルの `keyStats`（2〜3 個）に入る経験点 ×(1 + 0.2p)。ほかの能力は変えない。
- この分で総合B以上の割合が上がったら、`GROWTH.practiceMult` で戻す。

| ルーレット | 「背負った・プレスを受けた」場面の突破 +6 |
| 裏街道 | 「背後にスペースがある」場面の突破 +6 |
| チョップタッチ | 「縦に走りながら内側へ切り返す」場面の突破 +6 |
| シザース | 「止まった状態からの 1 対 1」の突破 +6 |
| チャンスメイカー | パスの候補 +1、決定的なパスの価値 +0.05 |
| スルーパス | 相手のラインが高いときの裏へのパスの精度 +4（`throughBall`） |
| サイドチェンジ | ロングボールの 30% が逆サイドへのパスになり、受けたサイドの 1 対 1 に +4 |
| ロングスロー | サイド攻撃が外に出たとき 25% でスローインが CK に近いクロス（質 −0.03）になる |
| インターセプト | パスカットの確率（相手のパスの精度 −4 相当）、カットする役に選ばれやすさ ×1.5 |
| スペースカバー | カウンターを受けたときの守備のスピード +4 |
| マンマーク | 受け手との勝負のマーカー側 +4 |
| カバーシャドウ | 自分のレーンの相手のパスの候補を減らす（守備の質 +3） |
| スライディングタックル | 1 対 1 の守備 +3、ファウルの確率 ×0.7 |
| PKストッパー | GK の PK の読み +8 |
| 飛び出し | GK の 1 対 1 と裏へのボールの処理 +4 |
| ラフプレー× | ファウル ×1.5、カード ×1.3 |

- **ドリブルの場面の決め方**：突破の判定の前に、その場の状況で場面を 1 つ決める。①中央で出せるパスがない（プレスを受けている）→ルーレット、②相手のプレスが高い・相手がボールハンター・25% の偶然 →ダブルタッチ、③カウンター・相手のラインが高いサイド →裏街道、④サイドでカットインを選んだとき →チョップタッチ、⑤相手のラインが低いサイド・止まった 1 対 1 →シザース。持っている技の場面になったときだけ効く。成功したら `move` に技を記録する。技を持っていない選手の突破も、場面に合う技の名前を `move` に入れる（3D でモーションを出すため。`skill` は付けない）。
- **金色の強さの確認**：金色を 1 人持つチームと持たないチームの勝率差を balance で出し、+2〜4pt を目安にする（1 人で試合をひっくり返さない）。
- **発動の記録と速報**：効いたときだけ `MatchEvent.skill` を付け、速報に「（ダブルタッチ）」「〔PK職人〕」のように短く足す。

### 4.2 エンジンへの組み込み

- 試合の作成時に、選手ごとに「特殊能力の補正表」（場面ごとの足す点数・倍率）を作り、`Actor` に持たせる。判定のたびに定義を探さない。
- 補正は今の判定式の「実効値」に足すだけにし、式そのものは変えない（P1・P2a の目標値を崩さないため）。
- 両チームが同じように特殊能力を持つので、平均得点などはほとんど動かない見込み。動いたら係数で戻す。

## 5. 習得条件

### 5.1 共通のしくみ

習得の判定はすべて `src/engine/skills/learn.ts` の `tryLearn(rng, player, candidates, baseChance, ctx)` に集める（特訓・イベント・合宿・CPU 校で共通）。

- 候補ごとの確率 ＝ 基本確率 × スタイルとの相性（`skillAffinity` に入っていれば ×(1.3 + 0.7p)）× 性格との相性（下表に入っていれば ×1.4）× 段階の補正（○ ×1、◎ ×0.5、金色は 5.4）。
- 段階のある系統は、今の段階の 1 つ上だけが候補（○がなければ◎は候補にならない）。習得したら下の段階と置き換える。× を持っている系統は、まず × を消すことが候補になる。
- 役割に合わないもの（フィールド選手の GK 系など）は候補にしない。

| 性格 | 習得しやすい（×1.4） |
|---|---|
| 努力家 | ケガしにくさ・スタミナ持続 |
| 情熱家 | 逆境・スタミナ持続・スライディングタックル |
| 冷静沈着 | PK 系・PKストッパー・カバーシャドウ |
| 職人気質 | FK の名手・CK の名手・ロングスロー・ヘディング系・ミドルシュート |
| 負けず嫌い | 大舞台・逆境・1対1系 |
| ムードメーカー | キャプテンシー |
| 慎重派 | 対人系・マンマーク・スペースカバー・インターセプト |
| ひらめき型 | ドリブル技 5 種・チャンスメイカー（金色の確率も ×2） |

### 5.2 特訓マス（Q1）

- 新しいマスの種類「特訓」（紫色）。通常マスの出やすさに 7 を足す（ほかの合計は 100）。1 年でおよそ 22 マス、止まるのは 6〜8 回の見込み。
- 止まると、そこまで使ったカードの練習の対象者全員が、その練習の候補で判定する（基本確率 6%。1 回で平均 2 人前後が習得する見込み）。

| 練習カード | 候補 |
|---|---|
| シュート | 1対1系・ミドルシュート・カーブシュート・消える動き |
| パス | チャンスメイカー・スルーパス・サイドチェンジ・クロスの名手の条件 |
| ドリブル | ドリブル技 5 種 |
| 守備 | 対人系・インターセプト・スペースカバー・マンマーク・カバーシャドウ・スライディングタックル |
| フィジカル | 空中戦（守備）系・ヘディング系・ケガしにくさ系 |
| 走り込み | スタミナ持続系・ケガしにくさ系 |
| 戦術ミーティング | 逆境系・キャプテンシー系・カバーシャドウ・スペースカバー |
| GK練習 | 1対1ストップ系・フィード系・飛び出し・PKストッパー |
| セットプレー | ヘディング系・ロングスロー・FK の名手・CK の名手 |
| PK練習 | PK 系・PKストッパー・大舞台系 |
| 休養 | 習得はなし。× を消す判定だけ（ラフプレー×・ケガしにくさ×） |

- 練習に関係する × を持つ選手は、同じ特訓で 15% で × が消える。

### 5.3 イベント

`EVENTS` に足す（青・白マス）。

| イベント | 内容 |
|---|---|
| OBの直伝 | 特殊能力を持つ OB が来て、同じポジションの区分の部員 1〜2 人に教える（OB の持つ特殊能力が候補。基本確率 35%） |
| スタッフの個別指導 | スタッフ 1 人が、担当分野に合う候補で部員 1 人を指導する（基本確率 30%）。× を持つ部員がいれば、それを消すことを優先（40%） |
| 先輩の背中 | 特殊能力を持つ 3 年生が、同じスタイルの 1・2 年生 1 人に伝える（25%） |
| 自主練の開眼 | 熟練度 60 以上の部員 1 人が、スタイルの相性の候補で判定（40%） |
| 悪い癖（赤マス、まれ） | 部員 1 人がラフプレー×か逆足×を持つ（すでにあれば何もしない） |

### 5.4 試合での成果と金色

試合が終わったら、自校の出場選手の `feats` を更新し、成果の条件を満たしたものはその場で判定する。

| 成果 | 結果 |
|---|---|
| 公式戦の 1 試合で 3 得点（Q3） | 1対1系の段階アップ（なし→○→◎）。すでに◎なら「1対1職人の条件」を満たす |
| PK 戦で 2 本止める（GK） | PKストッパーを習得（あれば何もしない） |
| 試合中の PK・PK 戦で通算 5 本連続成功 | PK 系の段階アップ |
| 全国大会の決勝で決勝点 | 大舞台系の段階アップ（×は消える） |
| 公式戦の 1 試合でヘディング 2 得点 | ヘディング系の段階アップ |

金色は「下の段階（◎）＋成果の条件」をそろえた選手だけが、低確率の判定を受ける。条件をそろえた後は、関係する特訓（2%）・OB の直伝で金色の OB がいるとき（20%）・条件を満たした試合の直後（10%）で判定する。

| 金色 | 前提 | 成果の条件（通算・公式戦） |
|---|---|---|
| 1対1職人 | 1対1◎ | 1 対 1 からの得点 5 |
| ボンバーヘッド | ヘディング◎ | ヘディングの得点 4 |
| 対人の鬼 | 対人◎ | 1 対 1 の守備の勝ち 30 |
| 空中戦の要 | 空中戦◎ | 守備の空中戦の勝ち 30 |
| 1対1の壁 | 1対1ストップ◎ | GK の 1 対 1 を止める 5 |
| フィードの名手 | フィード◎ | GK のロングボールからの得点 3 |
| PK職人 | PK◎ | PK の連続成功 8 |
| 両利き | 逆足×がない | 熟練度 80 以上＋シュートかドリブルの特訓で判定（1%） |
| FKの名手 | — | 直接 FK の得点 2 |
| CKの名手 | — | CK からのアシスト 3 |
| クロスの名手 | — | クロスからのアシスト 5 |

### 5.5 新入生

- 5% の確率でプラスの特殊能力（○か段階なし。スタイルの相性から）、4% でマイナス（×）を 1 つ持つ。両方のこともある。
- 金色は持たせない（両利きは Q5）。

### 5.6 合宿の差し込み口（P2c）

- `campLearning(state, rng, policy: PracticeKind[], playerIds: string[])` を作り、5.1 の判定を複数の選手に回すところまで実装してテストする。カレンダーからは呼ばない。

### 5.7 CPU 校

- CPU 校の選手も性格・スタイル・熟練度・特殊能力を持つ（試合の条件をそろえるため。Q8）。
- 熟練度は学年から簡略に決める（年度替わりに +25〜35）。特殊能力は年度替わりと秋の成長のときに、5.1 の判定を 1 回ずつ回す（基本確率は自校の卒業生の分布に合うよう balance で決める）。`feats` は持たない。金色は、◎ を持つ 3 年生だけ 1.5% で判定する。

## 6. キャプテン

- **指名の時期**：年度初め（スタッフの編成の後）に「キャプテン指名」の画面を出す（Q7）。冬の全国大会で 3 年生が引退してキャプテンがいなくなったら、そのときにも指名する。
- **候補**：全学年の部員。おすすめ順（性格の効果・キャプテンシー・学年・総合）に並べ、1 位を初期選択にする。
- **CPU 校**：3 年生から「総合＋キャプテンシーの補正」が最も高い選手を自動で選ぶ。
- **効果**（初期案）：

| キャプテンの性格 | チームへの効果 |
|---|---|
| 努力家 | チーム全体の練習効率 +3% |
| 情熱家 | ビハインド時、チーム全体の実効能力 ×1.02 |
| 冷静沈着 | 試合の最後の 1/4 で、チーム全体の判断 +2（パスのミスが減る） |
| 職人気質 | セットプレーのキッカーの実効値 +1 |
| 負けず嫌い | ランクが上の相手との試合で、チーム全体の実効能力 ×1.02 |
| ムードメーカー | チーム全体の調子が悪くなる確率 ×0.7、良くなる確率 ×1.3 |
| 慎重派 | 失点した後 2 区間、相手に流れ（モメンタム）が行く量を半分 |
| ひらめき型 | 自分の特殊能力の効果 ×1.1 だけ（チームへの効果は小さい） |

- キャプテンシー○／◎は、上の表に重ねてチーム全体の実効能力 ×1.01／×1.02。
- **試合に出ていないとき**：試合中の効果は半分（練習・調子の効果は出場と関係なく全部）。
- キャプテンシーを持っていてもキャプテンでなければ効果はない（詳細画面では薄く表示）。

## 9. テストとバランス

### 9.1 単体テスト

- 性格：練習の倍率（情熱家のフィジカル、職人気質の得意な練習）、調子の変わりやすさ、指導の素質が性格で決まること。
- 熟練度：試合と練習で上がる、伸ばしやすいスタイルで速い、スタイルを変えると 0 になる、選べないスタイルは選べない。
- 動きの範囲：`laneAffinity` の値。定位置・大外のみの選手が、多数の試合で担当ゾーン以外に関わる割合が 1 割未満。
- 特殊能力の段階：○ がないと ◎ を習得できない、◎ を習得すると ○ が消える、金色は前提と成果の条件がないと判定されない、× が消える。
- 習得条件：特訓マスの候補が練習カードで変わる、試合での成果（1 試合 3 得点で段階アップなど）。
- ドリブルの技：場面ごとに効く技が違う。発動が `MatchEvent` に記録される。
- キャプテン：指名、出場していないときは効果が半分、CPU 校の自動選出、3 年生の引退で指名し直し。
- セーブのマイグレーション（8.2）。

### 9.2 balance:full に足す項目（`scripts/phase2b.ts`）

| 項目 | 測り方 | 目安 |
|---|---|---|
| 卒業生の特殊能力の数の分布 | 自動プレイ（何年分）で卒業生のプラスの数のヒストグラム | 平均 1〜3 個 |
| 金色を持って卒業する割合 | 同上 | 数%（2〜5% を目安） |
| スタイル別の貢献 | ①全試合の出場時の得点・アシスト・奪取・空中戦の勝ち（80 分あたり） ②同じ能力の選手 1 人のスタイルだけを変えたチームの勝率（ポジションの区分ごと） | ②で区分の中の差が ±3pt 以内 |
| ゾーン別の関与率 | 動きの範囲ごとの `laneTouches` の割合 | 定位置・大外のみは担当外が 1 割未満 |
| キャプテンの効果量 | キャプテンの性格ごと・キャプテンシーの有無で、同じチームの勝率 | 参考（+1〜3pt 程度） |
| 金色 1 人の効果 | 金色を 1 人持つ・持たないで同じチームの勝率 | +2〜4pt |
| 総合値の分布 | 卒業時の総合のパーセンタイル（P2a と比べる） | インフレしていない |

- P1・P2a の項目（平均得点、PK 戦の割合、同格・2 段階上の勝率、評判の推移、采配の効果、総合B以上、カード、PK 戦の勝率、場面ごとの比較）はすべて今の範囲に収める。
- 自動プレイ（skilled）は、年度初めにおすすめ 1 位をキャプテンにし、スタイルは変えない。
- 計算時間は 10 分から数分延びる見込み。延びすぎたら quick と同じく試合数を環境変数で減らせるようにする。
