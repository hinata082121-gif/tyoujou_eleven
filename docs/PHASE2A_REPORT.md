# Phase 2a 完了報告（2026-10-09）

計画（`docs/PHASE2A_PLAN.md`、12章はすべて提案どおりで承認）に沿って実装しました。lint・型チェック・テスト（110件）・静的書き出し・`npm run balance:full` はすべて通っています。

## 1. 実装したもの

### スタッフ制度（SPEC 9章）
- OB からヘッドコーチ（必須）・GKコーチ・フィジカルコーチ・分析担当を雇う。枠は評判で 1〜3 人。
- 能力は現役時代の能力・主将経験・進路・隠しの「指導の素質」から決まる（名選手、名監督にあらず）。得意分野 1〜2 個だけ上限 100、ほかは 60〜80。
- 年度末に成長（上限に近いほど伸びにくい、60 歳で止まる）。60 歳から毎年 20% で勇退、68 歳で必ず勇退。12 月に引き抜きの予告、年度末に 70% で去る。
- ヘッドコーチがいないときは臨時コーチ。CPU 校も簡略化したスタッフ値（戦術眼・スカウティング）を持つ。
- ゲーム開始時とマイグレーション時に架空の OB を 5〜6 人作る（指導者の道と GK 出身が 1 人ずつは必ずいる）。
- 画面：部員タブの「部員／スタッフ」切り替え、候補の OB 一覧、OB の詳細（記録タブの OB からも開ける）、新しいゲームのヘッドコーチ選び、年度初めの編成（枠が減ったら外す人を選ぶまで進めない）。

### 作戦ノート（SPEC 10.5）
- ノート 3 冊・各 8 ルール。条件 8 種類・行動 4 種類。テンプレート 4 つ（パワープレイ・逃げ切り・疲労交代・PK準備）。
- 区間の終わりに上のルールから判定し、行動を全部実行できるルールだけ発動（1 試合 1 回）。自分で交代・戦術変更をすると関係するルールは止まる。
- 画面：メニュー → 作戦ノート（試合前からも開ける）。ルールの並べ替えは ▲▼、条件と行動は下から出るシートで追加、数字はステッパー、選手は「自動で選ぶ」か部員から指定。編集中のルールは 1 行の文章で表示。
- 試合前にノートを選ぶ（前回の選択が初期値）。観戦中は速報に「作戦ノート：○○を実行」、采配パネルにルールごとの状態（待機中／実行済み／停止中）。

### 試合中のファウル・カード・ケガ（SPEC 10.2）
- 1 対 1 の競り合いとそれ以外からファウル → イエロー、まれに一発レッド。2 枚目のイエローで退場し、人数が減ったまま戦う。GK が退場したら控えの GK を自動で入れる（交代枠を使う）。
- 退場した選手は次の公式戦 1 試合に出場停止（部員一覧に印、試合前に選べない）。
- 試合中のケガは軽傷・中程度・重傷。自校にケガ人が出ると観戦が止まり、入れる選手を選べる（選ばなければ自動）。交代枠がなければ人数が減る。
- フィジカルコーチの体力管理で、練習中・試合中のケガが減る。

### PK のスカウティングと PK 練習（SPEC 10.6）
- 読み ＝ PK駆け引き ＋ 分析担当のスカウティング × 0.04（両チーム）。分析担当がいれば試合前に相手のプレスとラインも見える。
- 進行カードに「PK練習」（全員の PK駆け引きが伸びる。GK コーチがいると GK の伸びが増える）。

### セーブ（スキーマ v3）
- Phase 1 の実際のセーブ（4 年遊んだもの）をテスト用に同梱し、v2 → v3 の移行を確認。移行すると架空の OB が加わり、臨時コーチが入り、ノートは空、CPU 校にスタッフ値が付く。1 年遊び続けられることもテストしている。

## 3. 仕様からのずれ・仮のもの

- **疲労交代（60%未満）があまり発動しない**：80 分の試合では、ピッチ上で一番疲れた選手でも 60% を切るのは 22% の試合だけ（切るのは平均 65 分）。90 分・延長ありの試合では増えます。承認どおり 60% のままにしています。
- **作戦ノートの効果はほぼゼロ**：テンプレートのうちパワープレイだけは少しプラス、逃げ切りは差なし、疲労交代はほぼ発動しない。自動プレイ（skilled）に入れると自分の采配と重なって同じランクへの勝率が 3 ポイントほど下がったため、skilled の初期値は「ノートなし」にし、ノートの効果は別の表で測っています（計画 10.2 では skilled にノートを足す予定でした）。
- **balance:full の時間**：10 分ほどになりました（スタッフあり・なしの比較で何年分も回すため）。CLAUDE.md を更新しています。
- **指導の素質**は仮の隠しパラメーターです（Phase 2b の性格に置き換える前提）。
- **寸評**は一番高い能力を言葉にするだけの簡単なものです。上限は表示していません。
- **ルールの削除・複製**はスワイプではなく「…」ボタンです（計画で認めた形）。
- 作戦ノートの「ポジション変更」の位置は、今の基本フォーメーションでの位置で指定します。
- 試合前の画面から作戦ノートを開いて戻ると、試合前に組んだ並びはおまかせに戻ります。

## 4. Phase 2b の前に決めてほしいこと

1. **疲労交代の初期値**：60% のままにするか、70% に上げるか（70% なら 80 分の試合の 8 割で発動、平均 63 分）。
2. **作戦ノートを強くするか**：今は「采配の手間を減らす道具」で、勝率はほぼ変わりません。勝率が上がる道具にしたいなら、テンプレートの中身（例：逃げ切りを 5-3-2 ではなく守備的・ライン低に）や、交代の効果を見直します。
3. **スタッフなしの成長が目標の下限（5%）をわずかに下回る**：PK練習のカードが入って、ほかの練習が少し減ったことが一因と見ています。このままでよいか、PK練習の出やすさ（今は 4）を下げるか。
4. **balance:full が 10 分かかる**：このままでよいか、スタッフの比較を quick 並みに減らすか。
