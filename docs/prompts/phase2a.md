## 1. スタッフ制度（SPEC 9章）

### 1.1 候補と枠
- スタッフは卒業生（OB）の中から選びます。
- ゲーム開始時（とPhase 1の既存のセーブ）には、架空のOBを数人生成して、すぐにヘッドコーチを選べるようにしてください。
- 枠は評判で決まります（SPEC 6章の表。弱小・そこそこ1人／中堅・強豪2人／名門3人）。
- **ヘッドコーチは必須**です。残りの枠には、GKコーチ・フィジカルコーチ・分析担当の中から配置します。
- **雇用と配置換えの時期**
  - 原則として年度初め（4月）に行います。
  - 欠員が出たときだけ、年度の途中でも補充できます。
  - 評判が下がって枠が減ったときは、次の年度初めに誰を残すかを選ばせてください。
- 候補がいないままヘッドコーチが抜けたときは、能力の低い「臨時コーチ」を自動で配置します。

### 1.2 能力
- 各スタッフは、内部では次の全パラメーターを持ちます。画面には、配置した役割で効くものを強調して表示します。
  - 指導力
  - 戦術眼
  - GK指導
  - 体力管理
  - スカウティング
- 表示は選手と同じランク（SS〜G）にします。
- **決まり方**
  - **現役時代の能力**で得意分野が決まります。例：GKだった人はGK指導、判断が高かった人やキャプテン経験者は戦術眼。
  - **卒業後の進路**で伸び方と、スタッフになれる時期が決まります。例：大学に進んだ人は4年後から、プロに進んだ人は引退後から。
  - 進路の種類は、計画で案を出してください。
  - **「名選手、名監督にあらず」**：指導力は、現役時代の強さより、性格や進路で決まる割合を大きくしてください。性格はPhase 2bで入るので、今回は仮の隠しパラメーターで構いません。

### 1.3 成長
- 在任中に成長します。成長のきっかけは、在任年数、担当分野の成果（例：GKコーチなら担当GKの成長や失点の少なさ、分析担当ならPK戦の勝ち）、大会成績です。
- **得意分野1〜2個**だけ、上限が100（SS）まで届く可能性があります。それ以外の能力の上限は60〜80程度にします。
- 上限の数値は画面に出さず、寸評でにおわせます（例：「この分野はまだ伸びしろがありそうだ」）。
- 上限に近づくほど伸びにくくします。年齢が上がると伸びが止まり、最後は勇退します。
- 優秀なスタッフほど、他校やプロに引き抜かれる確率が上がります。引き抜きの前に予告のイベントを出してください。

### 1.4 効果

| 役割 | 効果 |
|---|---|
| ヘッドコーチ | 全体の練習効率アップ（指導力）。結果のみモードでのAI采配の質（戦術眼） |
| GKコーチ | GK練習の効率アップ。GKのPK駆け引きの伸び |
| フィジカルコーチ | 疲労回復とケガの予防 |
| 分析担当 | PKの読み（1.5節と4章）。試合前に、相手の細かい傾向（プレス・ライン）を表示する |

- 練習効率の補正は、全部の効果を合わせても最大+15%程度にしてください（インフレ防止）。
- **CPU校のスタッフ**：CPU校も、簡略化したスタッフの値（戦術眼とスカウティング）を持ちます。評判やランクに応じてばらつかせてください。

### 1.5 画面
- スタッフ画面：今のスタッフ、空いている枠、配置換え、解任。
- 候補のOB一覧：現役時代の主な能力、進路、寸評、雇える時期。
- OBの詳細：在学中の成績を含めて表示します。

## 2. 試合中のカード・ケガ

- **ファウル**：守備の判定のときに、一定の確率でファウルが起きます。ペナルティエリア内ならPKになります（Phase 1の試合中のPKを、ファウルから起きる形に整理してください）。
- **カード**
  - ファウルからイエローカードが出ます。
  - 2枚目のイエローか、一発のレッドで退場になります。
  - 退場者が出たチームは10人になり、その状態は試合の判定に反映させます。
  - レッドカードで退場した選手は、次の公式戦に出場停止とします。イエローの累積による出場停止は、今回は入れません。
- **試合中のケガ**
  - ケガをした選手は交代が必要になります。交代は通常の枠を使います。
  - 交代枠が残っていなければ、そのチームは人数が減ったまま戦います。
  - ケガの重さに応じて、試合後に離脱する日数を決めます。
- **目安**：1試合あたりのイエローカードは両チーム合計2〜3枚、レッドカードは数十試合に1枚程度。balance で確認してください。
- **観戦画面**：カード・退場・ケガをテキスト速報とスコアボードに表示してください。

## 3. 作戦ノート（SPEC 10.5節）

- **条件**（いくつでも組み合わせられる）
  - 時間：○分以降、残り○分
  - スコア：○点リード、同点、○点ビハインド
  - 選手の状態：スタミナ○%未満、イエローカードを受けている、ケガ
  - その他：交代枠が残っているか、大会の種類
- **行動**
  - 選手交代（A→B）
  - フォーメーション変更
  - 戦術変更
  - ポジション変更
- **ルールの扱い**
  - 1つのノートにつき8ルールまでとし、優先順位を付けます。交代枠が足りないときは、優先順位の高いルールから実行します。
  - ノートは3冊まで保存でき、試合前の画面でどのノートを使うか選べます。
- **テンプレート**：「パワープレイ」「逃げ切り」「疲労交代」「PK準備」の4種類を用意してください。条件と行動の中身はSPEC 10.5節の表の通りです。
- **手動操作との関係**：観戦中に自分で交代や変更をしたら、関係するルールはその試合では止まります。
- **結果のみモード**（練習試合）でも作戦ノートを使います。ノートが決めていない部分は、ヘッドコーチの戦術眼に応じた質でAIが判断します。
- **観戦中の表示**：ルールが発動したら、テキスト速報に「作戦ノート：○○を実行」と表示してください。

## 4. PK（SPEC 10.6節）

- スカウティングの項を有効にしてください。
  - キッカー側の読み＝キッカーのPK駆け引き＋キッカー側チームの分析担当のスカウティング
  - GK側の読み＝GKのPK駆け引き＋GK側チームの分析担当のスカウティング
  - 分析担当がいないチームは、その項を0として扱います。CPU校は、1.4節の簡略化した値を使います。
- 試合中のPKも、同じ判定を使います。
- PK戦に参加できるのは、試合終了時にピッチにいた選手だけです。「PK準備」のテンプレートで、試合の最終盤にPK専門GKを投入できることを確認してください。

## 5. PK練習

- 練習カードに「PK練習」を追加します。対象は全員で、伸びるのはPK駆け引きです。
- GKコーチがいると、GKのPK駆け引きの伸びに補正がかかります。

## 7. テストとバランス

- **単体テスト**
  - スタッフの能力の生成、成長の上限（得意分野以外は上限を超えない）、勇退、引き抜き
  - 作戦ノートの条件判定、優先順位、交代枠が足りないとき、手動操作で止まること
  - カード・退場・ケガ
  - PKのスカウティング
  - セーブのマイグレーション
- **balance:full に追加する項目**
  - スタッフなしと、最高のスタッフ（3人）がいる場合で、一般入部の選手が総合B以上に届く割合を比べる。最高のスタッフでも12%程度までに抑えてください。
  - PK戦で、分析担当の能力差が最大のときの勝率。目安は55〜60%です。PK専門GKを使った場合の勝率も出してください。
  - 1試合あたりのイエローカード・レッドカード・ケガの数
  - 作戦ノート（4種類のテンプレート）を使った場合と使わない場合の勝率の差
  - Phase 1 の目標値（平均得点、PK戦になる割合、同格・2段階上への勝率、評判の推移）がすべて範囲内に収まっていること

## 8. 完了の条件

- スタッフを雇い、育て、勇退や引き抜きで入れ替わる流れが、自動プレイで5年以上途切れずに回ること。

- Phase 1 のセーブを読み込むと、マイグレーションで架空のOBが追加され、そのまま続けられること。
- `npm run lint`、`npm run test`、`npm run build`、`npm run balance:full` がすべて通り、目標値の範囲内であること。
