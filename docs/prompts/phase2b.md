## 1. 性格（8種類）

- 選手は全員、性格を1つ持ちます。
- Phase 2a で仮に入れた隠しパラメーター「指導の素質」は、性格に置き換えてください（スタッフの指導力の決まり方に使います）。

| 性格 | 練習の得意 | 試合でのメンタル | キャプテンにしたとき | 指導の素質 | 伸ばしやすいスタイル |
|---|---|---|---|---|---|
| 努力家 | 全般に安定して伸びる | 調子の波が小さい | チーム全体の練習効率が少し上がる | 高 | どれでも平均的 |
| 情熱家 | フィジカル・走り込み | 終盤に強い。熱くなってカードをもらいやすい | ビハインド時にチームの士気が上がる | 中 | ボックストゥボックス、ボールハンター、ストッパー |
| 冷静沈着 | 戦術ミーティング・パス | PKに強い。調子の波が小さい | 終盤の判断ミスが減る | 高（戦術眼） | No.10、リンクマン、カバーリング、ビルドアップ型 |
| 職人気質 | 得意な練習1つが大きく伸び、ほかは普通 | セットプレーに強い | 効果は小さい | 専門分野に強い | ポーチャー、クロッサー、砲台、ボックスキーパー |
| 負けず嫌い | 試合で得る経験点が多い | 格上相手に強い。負けると調子が落ちる | 格上との試合でチームの士気が上がる | 中 | ストライカー、インサイドドリブラー、ボールハンター |
| ムードメーカー | 普通 | 調子の波が大きいが、上がりやすい | チーム全体の調子が安定し、上がりやすくなる | 低〜中 | スピードスター、ウイングドリブラー、攻撃的サイドバック |
| 慎重派 | 守備系が得意、シュート系が苦手 | ミスが少ない。大舞台では少し萎縮する | 失点した後に崩れにくい | 中（分析） | アンカー、カバーリング、空中戦の番人 |
| ひらめき型（まれ） | 伸びは大きいが、当たり外れも大きい | 波が大きく、ここ一番で特殊能力が発動しやすい | 効果は小さい | 低（名選手、名監督にあらず） | ウイングドリブラー、インサイドドリブラー、No.10 |

- ひらめき型は新入生の数%程度にしてください。
- **キャプテン制度を新しく追加します。**
  - 年度初めに、部員から1人をキャプテンに指名します。
  - キャプテンの性格の効果と、特殊能力「キャプテンシー」の効果がチームに乗ります。
  - キャプテンが試合に出ていないときは、効果を弱めてください。
  - CPU校も、自動でキャプテンを決めます。

## 2. プレースタイル（全20種）

### 2.1 基本ルール
- 1人1つだけ持ちます。サブのスタイルは持てません。
- **プレースタイル熟練度**を持ちます。試合と練習で上がり、上がり方は性格で変わります（1章の表）。
- 熟練度が高いほど、次の2つの効果が強くなります。
  - 試合で、そのスタイルらしいプレーが起きやすくなる
  - スタイルに合った能力が伸びやすくなる
- **スタイルは変更できます。** 変更すると熟練度は0から始まり、すぐには力を発揮できません。

### 2.2 一覧

「FW/MF」「MF/DF」は、どちらのポジションで使っても効果を発揮するという意味です。

| ポジション | スタイル | 動きの範囲 | 特徴 |
|---|---|---|---|
| FW | ストライカー | 自由 | ゴール前での決定力 |
| | ポストプレーヤー | 定位置 | 体を張ったキープと空中戦 |
| | スピードスター | 自由 | 裏への抜け出しとカウンター |
| | リンクマン | 自由 | 少し低い位置でMFとFWをつなぐ |
| | ポーチャー | 自由 | ペナルティエリア内に特化し、そこで大きな力を出す。組み立てとポストプレーには参加しない |
| FW/MF | ウイングドリブラー | 主に大外 | 大外に張って仕掛けるドリブラー |
| | インサイドドリブラー | 主に内側 | 内側に入り、味方と近い距離のコンビネーションで突破する |
| MF | No.10 | 定位置 | 視野とパスで決定機を作る |
| | ボックストゥボックス | 自由 | 攻守に走り回る運動量 |
| | アンカー | 定位置 | 中盤の底で守備を固める |
| | ボールハンター | 自由 | 相手に積極的に奪いにいく |
| MF/DF | クロッサー | 大外のみ | 大外からクロスを多く入れる |
| DF | ストッパー | 自由 | 対人の強さ |
| | カバーリング | 自由 | 判断とスピードで背後を守る |
| | 攻撃的サイドバック | 大外のみ | オーバーラップとクロス |
| | ビルドアップ型 | 自由 | 後方から攻撃を組み立てる |
| | 砲台 | 定位置 | 前線へのロングボールや、逆サイドへのボールで打開する |
| GK | ボックスキーパー | 定位置 | 反応とセービング |
| | スイーパーキーパー | 自由 | 飛び出しと足元の技術 |
| | 空中戦の番人 | 自由 | クロスへの強さ |

### 2.3 動きの範囲

試合エンジンのゾーン判定（左・中央・右）に、次のように反映してください。

| 動きの範囲 | 扱い |
|---|---|
| 自由 | 特に制限なし |
| 定位置 | ゲームが決めたポジションからあまり動かない。担当ゾーン以外への関与を小さくする |
| 大外のみ | 左右どちらか一方のゾーンだけでプレーする |
| 主に大外／主に内側 | そのゾーンに関わる割合を高くするが、ほかのゾーンにも状況次第で入る |

- 2D・3D表示（Phase 3・4）で選手の位置を決めるときにも、この設定を使えるデータ構造にしてください。
- **新入生と既存の選手のスタイル**：ポジションと能力の傾向から決めてください。

## 3. 特殊能力

### 3.1 表記と段階
- プラスの特殊能力は「○」、マイナスは「×」、○の上位版は「◎」で表記します。
- 最上位の特殊能力は**金色**で表示します。
  - 呼び名は仮に「レジェンドスキル」とし、`names.ts` で変えられるようにしてください。
  - 「金特」という呼び名や、既存のゲームの特殊能力アイコンの見た目は真似しないでください。
- 段階のある系統では、下の段階を持っていないと上の段階を習得できません（例：対人◎がないと、対人の鬼は習得できない）。上の段階を習得したら、下の段階と置き換えます。

### 3.5 効果量の目安
- ○＜◎＜金色の順に効果を強くします。
- 効果量の具体的な数値は、計画で案を出してください。
- 金色の特殊能力は、持っている選手がいるとはっきり分かる強さにします。ただし、1人で試合をひっくり返すほどにはしないでください。

### 3.6 入手方法

| 方法 | 内容 | 実装 |
|---|---|---|
| 特訓マス | 使った練習カードの種類に応じた候補から、確率で習得する | 今回 |
| イベント | OBやスタッフから教わる、など | 今回 |
| 試合での成果（難易度高） | 例：1大会でハットトリック → 1対1系の段階アップ、PK戦で2本止める → PK系、直接FKで得点 → FKの名手の条件の一部、全国大会の決勝で決勝点 → 大舞台系 | 今回 |
| 合宿 | 合宿の練習方針に応じて、複数の選手が習得のチャンスを得る | Phase 2c（今回は差し込み口だけ作る） |

- **金色の特殊能力**：下の段階を持っていることを前提に、試合での成果と、低確率の特訓・イベントを組み合わせて習得させます。
- **プレースタイルとの相性**：スタイルに合った特殊能力は習得しやすくします（例：ストライカー→1対1系、ポーチャー→1対1系・ヘディング系、No.10→チャンスメイカー・スルーパス、ウイングドリブラー→ドリブルスキル・クロス系、ボックスキーパー→1対1ストップ系、砲台→サイドチェンジ・フィード的な長いパス）。
- **性格との相性**：性格で、習得しやすさに補正をかけます（例：職人気質→セットプレー系、冷静沈着→PK系）。
- **マイナスの特殊能力**：特訓やスタッフのイベントで消せるようにします。
- **新入生**：数%の確率で特殊能力を最初から持たせます（主に○と×）。

### 3.7 画面
- 選手の詳細画面に、性格、プレースタイルと熟練度、特殊能力を表示してください。特殊能力は、○・◎・金色・×で色分けします。
- 特殊能力の一覧と説明を見られる画面（図鑑）を作ってください。
- 部員一覧で、スタイルと特殊能力で絞り込みや並べ替えができるようにしてください。

## 5. テストとバランス

- **単体テスト**
  - 性格の効果
  - 熟練度（変更すると0になる）
  - 動きの範囲（定位置・大外のみの選手が、担当ゾーン以外にほとんど関わらない）
  - 特殊能力の段階（下の段階がないと習得できない、上の段階で置き換わる）
  - 習得条件
  - キャプテン
  - セーブのマイグレーション
- **balance:full に追加する項目**
  - 卒業生が持っている特殊能力の数の分布（目安：プラスの特殊能力が平均1〜3個）
  - 金色の特殊能力を1つ以上持って卒業する選手の割合（目安：数%）
  - プレースタイル別の出場時の貢献（得点、アシスト、奪取など）。突出して強いスタイルがないこと
  - 動きの範囲のゾーン別の関与率
  - キャプテンの効果量
- Phase 1・2a の目標値は、すべて範囲内に収めてください。
  - 平均得点、PK戦になる割合、同格・2段階上への勝率、評判の推移、采配の効果
  - 総合B以上の割合
  - カードの枚数
  - PK戦の勝率
  - 場面ごとの比較
- 特殊能力の効果で能力のインフレが起きていないか（総合値の分布）も確認してください。
