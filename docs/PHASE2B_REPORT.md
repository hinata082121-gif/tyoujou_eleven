# Phase 2b 完了報告（2026-10-11）

計画（`docs/PHASE2B_PLAN.md`。Q5 だけ推奨と違う形で承認）に沿って実装しました。lint・型チェック・テスト（149件）・静的書き出しは通っています。`npm run balance:full` は 1 項目（パワープレイの効果）だけ目安をわずかに下回りました（3章）。

## 1. 実装したもの

### 性格（8種類）
- 努力家・情熱家・冷静沈着・職人気質・負けず嫌い・ムードメーカー・慎重派・ひらめき型。
- 練習の伸び方（職人気質は得意な練習、ひらめき型は練習ごとに振れる）、調子の揺れ方、試合でのメンタル（情熱家は終盤、負けず嫌いは格上相手、慎重派は大舞台で少し弱い）、特殊能力の身につけやすさ、OB になったときの指導の素質に効きます。

### プレースタイル（20種類）と熟練度・動きの範囲
- 主ポジションと適性○以上のポジションのスタイルから選べます。変えると熟練度は 0 に戻ります（確認あり）。
- 熟練度はスタイルに合う練習と試合出場で上がり、試合での効果・能力の伸び（得意な能力 最大 +20%）・特殊能力の身につけやすさに効きます。
- 動きの範囲（自由・定位置・大外のみ・主に大外・主に内側）で、試合でどのレーンに関わるかが変わります。今いる枠がスタイルの区分に入らないときは「自由」として扱います。

### 特殊能力（○・◎・金色・×）
- 系統は ○→◎→金色 の順に上がり、× は消すまでその系統の ○ を覚えられません。金色（レジェンドスキル）は 11 種類。
- 入手：特訓マス（新しいマス。赤紫）、イベント（OB の直伝・スタッフの個別指導・先輩の背中・自主練の開眼・悪い癖）、試合での成果（公式戦の 1 試合で 3 得点 → 1対1系、PK 戦で 2 本止める → PK ストッパーなど）、合宿は差し込み口だけ。
- 両利き：新入生は持たず（0%）、「逆足×がない・熟練度 80 以上・シュートかドリブルの特訓で 1%」でだけ身につきます。利き足の「両足」はなくしました。
- 試合では、判定の実効値に点数を足す（○ 2.5・◎ 5・金色 12）か、場面ごとの効果（ドリブル技、スルーパス、サイドチェンジ、ロングスローなど）。速報に「〔特殊能力名〕」「（ドリブル技名）」が付きます。
- CPU 校の選手も性格・スタイル・熟練度・特殊能力を持ち、年 2 回の簡略な判定で増えます。

### キャプテン
- 年度初めのスタッフ編成の後と、3 年生の引退でキャプテンがいなくなったときに指名します（おすすめ順に並べて表示）。CPU 校は自動で選びます。
- 性格ごとにチームへの効果（努力家は練習効率、ムードメーカーは調子、情熱家はビハインド時など）。試合に出ていないときは効果が半分。

### 画面（375px で確認。横にはみ出しなし）
- 選手の詳細：性格・スタイルと熟練度・特殊能力のチップ（○ 緑・◎ 青・金色 金・× 灰色）。「スタイルを変える」から変更。
- メニュー → 特殊能力図鑑：レジェンドスキル・系統ごとのタブ。持っている人数をタップすると部員一覧をその特殊能力で絞り込みます。
- メニュー → チーム（キャプテン）、キャプテン指名の画面、部員一覧のスタイル・特殊能力の絞り込みと並べ替え、試合結果に習得した特殊能力。

### セーブ（スキーマ v4）
- v3（Phase 2a）のセーブを読み込むと、全員に性格・スタイル・学年に応じた熟練度と特殊能力（3 年生でプラス 1 個前後、金色なし）が付きます。「両足」の選手は右か左に振り分け、逆足×は付けません。キャプテンはひとまず自動で選びます。
- Phase 2a で作ったセーブ（6 年目）を使ったテストで、読み込み後に 1 年遊び続けられることを確かめています。

## 3. 仕様からのずれ・仮のもの

- **パワープレイの効果が目安をわずかに下回る**：同じ設定でも実行するたびに +2.0〜4.0pt で揺れています（P2a は +3.7pt）。調べた範囲では、パワープレイを使ったときの「中央へのパスからの得点」が P2a より伸びにくくなっています。性格・スタイル・特殊能力をすべて切っても戻らないので、動きの範囲（レーン）の仕組みへの置き換えが原因と見ていますが、どこかは特定できていません。
- **名門への到達**：12 年で 55%（P2a は 65%）。上の調整で 15% から戻しました。
- **金色の存在感**：計画にない効果です。金色を持つ選手は、その場面以外でも実効能力が少し上がります。
- **金色の内訳がクロスの名手に偏る**：条件の成果（クロスからのアシスト 1 回）が一番届きやすいため。
- **特訓マスの色**：「必ず止まる」マス（紫）と見分けにくかったので、赤紫にして凡例に「特訓」を足しました。
- **キャプテンシー◎**：+4.1pt で、目安（+1〜3pt）より少し強めです。
